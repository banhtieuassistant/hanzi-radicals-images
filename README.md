# hanzi-radicals-images

Ink-wash illustrations for the **50 Basic Chinese Radicals** lesson set on [hanzi.ca](https://www.hanzi.ca) — one image per radical, one page per radical.

## Files

- `radical-01-ren.png` … `radical-50-zou.png` — 50 illustrations, each under 200 KB
- `index.html` — simple gallery page (used by the Cloudflare Pages site)
- `README.md` — this file
